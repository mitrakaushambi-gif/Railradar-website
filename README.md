#Railradar Website

*Railradar* is a real-time web application that integrates comprehensive railway network tracking, route corridors, elevation contours, and live weather conditions across train routes.

---

#Features

- *Live Railway Corridor Tracking:* Monitor railway network corridors and telemetry data in real time.
- *Interactive Map Layers:* Custom map styles and geospatial visualization powered by *MapTiler* and *OpenTopo*.
- *Real-Time Weather Integration:* View live weather conditions along railway corridors via *OpenWeather API*.
- *Comprehensive Train Database:* Fast searching and filtering of railway status, routes, speeds, and coordinates.
